# A2C Sensor Tools 0.2.0-beta.8

Published: 2026-10-27

This beta adds a live fusion-state display and periodic fusion diagnostics to
the IMU Dashboard. It also includes the Windows dashboard and firmware updater,
with Kvaser CANlib and PEAK PCAN-Basic adapter support.

## Changes

- A simple Fusion label above the live plots shows starting, running, fallback,
  acceleration rejection, recovery and stale status. Hover over it for details.
- Periodic-message dropdowns now include `0x18/0x12`, `0x18/0x13` and
  `0x18/0x14` for fusion state, rejection metrics and counters.
- Live polling requests the fusion summary once per second on compatible
  firmware. With polling off, the dashboard displays incoming periodic replies.
- Linear acceleration has readable XYZ values and separate monitor statistics.
- IMU setting changes are serialized to allow sensor reconfiguration to finish
  before sending the next setting.

Periodic fusion diagnostics require sensor firmware **0x0136 or newer**.
Firmware **0x0135** supports the direct summary query used by live polling.

## Download and run

Download `A2C-Sensor-Tools-0.2.0-beta.8-Windows-x64.zip`, extract the entire ZIP
to a local folder, and start `A2C-IMU-Dashboard.exe` or
`A2C-Sensor-Firmware-Updater.exe`. Keep the `_internal` folder beside the EXEs.
Python and Qt are included; install the appropriate Kvaser or PEAK driver/API
separately. The applications are unsigned. Firmware is supplied separately.
